## Problem and implementation

1. **U.S. yield units:** supporting metrics previously used a bare level such as `5` and a relative percentage such as `+0.81%`. The producer now emits an explicit dated yield level (`5.00%`) and absolute basis-point change. Formula: `(latest yield in percentage units - previous yield) * 100`, rounded to two decimal bp with zero normalized. Tests cover positive, fractional negative, zero and invalid observations. Stale observation dates are visible; cross-date data is not used to assert a daily cause.
2. **Depth inflation:** the existing #28 proposal's 900-character / four-block threshold is retained and applied to prose paragraphs, excluding masthead, SVG and source-list material. Long chart descriptions cannot make a short article pass. Long-history SVG descriptions summarize endpoints and range; the original data-values attribute retains exact values. Existing five-session accessibility dates remain available.
3. **Article limits:** U.S. market commentary now states the observation-date relation, missing dollar evidence and limits of index-only readings. It is rendered as a distinct section rather than attached to the lead. No sector, company or institution facts were invented. Empty U.S. sector/company coverage explicitly prevents production verification, even when prose is long. **Operational impact if merged:** existing index-only U.S. output will HOLD until dated sector/company evidence is connected. The parser now records requested date and the last eight returned observation dates, distinguishes provider error / missing row / invalid close, rejects zero and non-finite values, and never logs arbitrary provider prose. Existing HOLD semantics remain.
5. **PDF compatibility:** the renderer no longer indexes a nonexistent fourth chart. It accepts zero/three/four charts, spans the last odd chart, labels the real observation count rather than a hardcoded five sessions, and skips empty sections. The research model now retains the article's narrative facts and separately labeled analysis, omits null institution copy, and formats index levels to two decimals. Body type is 10.5pt; source type is 8pt. Licensed Korean TTF paths can be configured by `MOTUS_PDF_FONT_REGULAR` / `MOTUS_PDF_FONT_BOLD` without changing credentials. Font embedding is checked from PDF font descriptors. Daily page limit is three, consistent with the MASTER target rather than a forced two-page cap.
